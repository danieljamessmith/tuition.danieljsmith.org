# tuition.danieljsmith.org

Private Mathematics and Physics tuition, GCSE to University level: what is
offered, how it works and how to get in touch.

Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com)
on the AstroWind template (`vendor/` is its integration), deployed to GitHub
Pages from `main`. `npm ci`, then `npm run dev` to serve it locally;
`npm run check` (Astro, ESLint, Prettier) is what CI runs.
